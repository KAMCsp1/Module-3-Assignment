Library Management System

Project Description

This project is a simple Library Management System created with Python.

The program allows a user to:

Add books to a library

List all books

Search for a book by title or author

Exit the program

The project is designed to show how to use functions, modules, classes, objects, loops and conditionals.

Files

book.py

Contains the Book class.

Each Book object stores:

Title

Author

ISBN

The class also contains methods for displaying and returning book information.

library_manager.py

Contains the main program and the following functions:

add_book()

list_books()

find_book()

main()

How to Run

Make sure book.py and library_manager.py are in the same folder.

Run:

python library_manager.py
